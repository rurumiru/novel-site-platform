Платформа для публикации и чтения онлайн-новелл: авторский кабинет, чтение по главам, форум, обзоры и панель модерации/администрирования.

Построена на **Laravel 12** с использованием **Filament** (админка), **Livewire** (интерактивный фронтенд), **Tailwind CSS** и **Vite**.

## Возможности

- **Каталог и чтение** — новеллы, тома и главы, прогресс чтения, закладки, избранное.
- **Авторский кабинет** — создание и редактирование новелл, импорт глав, статистика.
- **Монетизация** — подписки на новеллы, поглавная покупка контента, промокоды. *(Приём платежей и вывод средств в этой публичной версии удалены.)*
- **Социальные функции** — комментарии, рейтинги, обзоры, форум.
- **Коллаборация** — бета-ридеры, редакторы новелл, переводческие команды.
- **Модерация и роли** — система ролей и прав на базе `spatie/laravel-permission`, уровни доверия, бейджи.
- **Админ-панель** — Filament.
- **Гео-ограничения** — middleware блокировки доступа к ограниченному контенту по региону.
- **Мультидоменность** — выбор базы данных по домену через middleware.
- **Публичный REST API** — `/api/v1` (новеллы, главы, авторы, поиск).

## Технологический стек

| Слой | Технология |
|------|-----------|
| Backend | PHP 8.2+, Laravel 12 |
| Админка | Filament 3 |
| Интерактив | Livewire |
| Фронтенд | Tailwind CSS 4, Vite 7, Quill, markdown-it |
| База данных | PostgreSQL (основная), опциональная синхронизация в MySQL |
| Кеш / очереди / сессии | Redis |
| Хранилище файлов | S3-совместимое (Flysystem) |
| Почта | SMTP |

## Требования

- PHP **8.2+** с расширениями, требуемыми Laravel (`pdo_pgsql`, `mbstring`, `gd`, `intl`, `zip` и др.)
- Composer
- Node.js 18+ и npm
- PostgreSQL
- Redis
- S3-совместимое хранилище (опционально)

## Установка

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd shiba

# 2. Установить зависимости
composer install
npm install

# 3. Создать файл окружения и сгенерировать ключ
cp .env.example .env
php artisan key:generate

# 4. Настроить .env (см. раздел «Конфигурация»)

# 5. Выполнить миграции (и сидеры при необходимости)
php artisan migrate
php artisan db:seed

# 6. Создать символьную ссылку на хранилище
php artisan storage:link

# 7. Собрать фронтенд-ассеты
npm run build
```

> ⚠️ Это архивный код — без донастройки окружения запуск «из коробки» не гарантируется.

## Запуск (разработка)

Запустить сервер, обработчик очередей, логи и Vite одной командой:

```bash
composer dev
```

Либо по отдельности:

```bash
php artisan serve
php artisan queue:listen --tries=1
npm run dev
```

Приложение будет доступно на `http://localhost:8000`, админ-панель Filament — по маршруту панели (по умолчанию `/admin`).

## Планировщик задач

Регулярные задачи объявлены в [routes/console.php](routes/console.php):

| Команда | Расписание | Назначение |
|---------|-----------|-----------|
| `auth:clear-resets` | каждые 15 минут | очистка устаревших токенов сброса пароля |
| `app:auto-unlock-chapters` | ежедневно 06:00 | автоматическая разблокировка глав |
| `eriiba:recalc-trust` | ежедневно 03:30 | пересчёт уровней доверия пользователей |
